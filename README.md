# 車の実質コスト比較ツール(TCO計算)

新車価格ではなく「実質コスト」で車を比較するWebツール。日本版 Edmunds True Cost to Own を目指したものです。
残価(売却価格)・自動車税・重量税・自賠責・車検整備費・燃料費・任意保険・駐車場・消耗品まで含めた
総保有コスト(TCO)を、保有年数や年間走行距離などの個人条件で計算します。

**公開ページ:** `docs/index.html`(GitHub Pages)。単一HTMLでオフラインでも動作します。

## 使い方(開発)

- `index.html` — 開発版(`data.js` / `engine.js` を外部読み込み)
- `node test.js` — 計算エンジンのコンソール検証
- `node build.js` — 単一HTML化して `car_tco.html` と `docs/index.html` を生成

`car_tco.html` / `docs/index.html` は生成物なので直接編集しないでください。

## 主な機能

- 10車種の総コスト・年あたりコストのランキング表と積み上げ棒グラフ
- 保有年数(1〜15年)・年間走行距離・燃料単価・駐車場代・任意保険のカスタマイズ
- 売却/乗りつぶし、新車/中古3年落ち購入の切り替え
- 「最適売却時期」ビュー: 保有1〜15年をスイープした年あたりコスト折れ線と最小コスト年マーカー
- 「意外な結論」の自動ハイライト(高い車が実は年コストで安い等)

## データ出典

- 残価率: カーセンサー/グーネット等の中古車掲載相場・買取相場情報サイトを参考にした概算(3/5/7/10年の4点、基準日は `data.js` の `DATA_DATE`)
- 自動車税: 総務省の税額表(2019年10月以降登録の税率)
- 重量税・自賠責: 国土交通省・損害保険料率算出機構の公表料率をもとにした概算
- 燃費: 各社公表のWLTCモード値 × 補正係数0.85

## 免責

残価率は中古車掲載相場ベースの概算です。実際の売却額・保険料・整備費は車の状態・グレード・地域などの
条件により変動します。本ツールの計算結果は参考情報であり、正確性を保証するものではありません。
